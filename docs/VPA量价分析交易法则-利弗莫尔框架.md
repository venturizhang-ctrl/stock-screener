# VPA量价分析交易法则

> 基于Wyckoff量价理论 + 利弗莫尔交易原则 + A股周线实操框架  
> 适用：A股主板/创业板（剔除科创板、北交所、ST）  
> 时间框架：**周线定方向 → 日线找买点**

---

## 一、核心原理（永远记住这三句话）

```
1. 量是"努力"，价是"结果"——努力和结果不匹配时，就是信号
2. 周线不会被主力操控，日线可以——所以周线先行
3. 不要预判，让市场自己证明方向——等突破再动手
```

---

## 二、第一步：周线筛选（每周五收盘后做一次）

打开VPA扫描，参数设置：**换手率≥5%，市值≥20亿**。

只看三种信号：

### 🟢 可以买的信号

| 信号 | 条件 | 含义 |
|------|------|------|
| **吸筹确认-突破** | 前4周换手>100%+横盘<8%+本周放量涨>5% | 主力吸筹完成，开始拉升 |
| **震仓反弹 Spring** | 恐慌周大跌+放量 → 本周强力反弹收复80% | 洗盘结束，空头被消灭 |
| **低位放量突破** | 量比>1.5+涨>5%+60周位置<50% | 底部启动第一波 |

### 🔴 必须回避的信号

| 信号 | 条件 | 含义 |
|------|------|------|
| **高位滞涨** | 换手>30%+涨不动+60周位置>75%+收盘弱 | 主力在出货 |
| **放量下跌** | 周跌>5%+放量>1.5倍 | 恐慌未结束，不知道底在哪 |

### ⚪ 只看不动的信号

| 信号 | 条件 | 处理 |
|------|------|------|
| **吸筹区（未突破）** | 高换手横盘，但本周还没涨 | 加入自选，每天看一眼 |
| **缩量上涨** | 量缩价涨，已在上升趋势中 | 如果已持有，继续拿；没买就别追 |
| **巨量换手推升** | 5周换手>250%+暴涨>20% | 已持有的减仓，没买的不追 |
| **中性** | 无信号 | 不看 |

## 三、第二步：趋势确认（人工判断，1分钟/股）

VPA给出了信号，但你必须亲自确认三件事：

### 检查清单

```
□ 周线MA10、MA20、MA60是否多头排列？（MA10 > MA20 > MA60）
□ 本周收盘价是否在所有均线之上？
□ 60周位置是否在 30%~85% 之间？（太低=没人关注，太高=随时见顶）
```

### 判断规则

| 趋势状态 | 特征 | 处理 |
|----------|------|------|
| ✅ 强势上升 | MA10>MA20>MA60 + 价在线上 | **正常做** |
| ✅ 上升趋势 | 价>MA20 + MA20>MA60 | **可以做，仓位减半** |
| ⚠️ 震荡 | 价在MA20附近来回 | **只做吸筹确认，其他信号忽略** |
| ❌ 下降趋势 | 价<MA20 + MA20<MA60 | **任何信号都不做** |

## 四、第三步：日线找买点（只在VPA周线信号确认后）

周线说"可以关注了"，但具体什么时候买，看日线。

### 买点一：缩量回踩（最稳，适合新手）

```
条件：
  ① 股价回踩到10日线或20日线附近
  ② 当日成交量 < 前5日均量的70%（缩量 = 抛压耗尽）
  ③ 收盘价 > 开盘价（收阳线）
  ④ 收盘在当日K线上半部分（>60%位置）

动作：收盘前15分钟买入（14:45-15:00）
止损：20日线下方2%
```

### 买点二：突破确认（激进，适合有经验者）

```
条件：
  ① 周线本周是"吸筹确认-突破"信号
  ② 下周一/周二，日线价格突破上周周线最高价
  ③ 当日量比 > 1.5（放量突破）
  ④ 收盘在当日K线上半部分

动作：突破当天收盘前买入（不要盘中追）
止损：上周周线最低价
```

### 买点三：震仓结束（抓反弹，适合短线）

```
条件：
  ① 上周是恐慌大跌（跌>5%+放量）
  ② 本周一开始反弹，连续2天收在恐慌周收盘价上方
  ③ 反弹第二天量比 > 1.2

动作：第二天收盘确认后买入
止损：恐慌周最低价
```

## 五、仓位管理

利弗莫尔的核心原则：**先小仓位试，对了再加。**

```
总资金分4份：

第一份（25%）：周线信号确认 + 日线买点出现 → 买入
第二份（25%）：买入后涨了3%以上 + 日线继续放量 → 加仓
第三份（25%）：涨了8%以上 + 周线趋势保持 → 再加
第四份（25%）：永远留着，不投入（利弗莫尔说"现金是氧气"）
```

**任何时候都不要满仓。** 利弗莫尔破产过好几次，每次都是因为满仓+杠杆。

## 六、持仓和卖出

### 持仓期间每周检查（周五收盘后）

打开VPA，看这只股的周线信号有没有变化：

| 本周信号 | 动作 |
|----------|------|
| 🟢 缩量上涨 | ✅ 正常，继续持有 |
| 🟢 连续放量上攻 | ✅ 强势，可以加第三份 |
| ⚠️ 巨量换手推升 | ⚠️ 减仓一半 |
| 🔴 高位滞涨 | 🚫 **全部卖出** |
| 🔴 放量下跌 | 🚫 **全部卖出，别犹豫** |
| ⚪ 中性 | 持有不动 |

### 硬止损（必须执行，没有例外）

```
买入价下方 7% → 无条件卖出
（利弗莫尔："亏7%说明你错了。别问为什么，先出来。"）
```

### 移动止盈

```
涨了 10% → 止损提到成本价（保本）
涨了 20% → 止损提到涨10%的位置（锁定一半利润）
涨了 30% → 止损提到20日线（让利润跑）
```

## 七、禁止做的事（利弗莫尔的"负面清单"）

```
❌ 1. 日线看到一根阳线就买（没有周线确认 = 赌博）
❌ 2. 下跌趋势里抄底（周线下降+日线反弹 = 诱多）
❌ 3. 高位追涨（60周位置>90% + 放量 = 接盘侠）
❌ 4. 不止损（亏7%不走 → 亏20% → 亏50% → 永远解不了套）
❌ 5. 同时持超过3只股（利弗莫尔最多3只，精力是有限的）
❌ 6. 听消息买股票（"内幕消息"是亏钱最快的路）
❌ 7. 跌了加仓摊平成本（"向下摊平"是利弗莫尔认为最蠢的操作）
❌ 8. 盘中看到大涨冲动追进去（等到收盘前15分钟再决定）
```

## 八、每周操作流程（总结）

```
📅 周五收盘后（30分钟）：
  1. 打开VPA，扫描换手≥5%、市值≥20亿
  2. 筛选出 🟢吸筹确认 / 🟢震仓反弹 / 🟢低位放量突破 的股票
  3. 人工确认趋势（MA排列 + 60周位置）
  4. 选出最多3只候选，记录在本子上

📅 周一~周四（每天10分钟）：
  5. 看候选股有没有出现日线买点（缩量回踩/突破确认）
  6. 有买点 → 收盘前买入第一份（25%）
  7. 没有买点 → 不动，继续等

📅 下周五收盘后（20分钟）：
  8. 检查持仓的周线信号
  9. 信号变坏 → 卖出 / 信号保持 → 考虑加仓
  10. 重新扫描，更新候选池

📅 每月初：
  11. 复盘：这个月赚了多少/亏了多少？哪些操作违反了规则？
  12. 把违反规则的操作写下来，下个月不再犯
```

## 九、预期收益和心态

```
正常的交易者：
  一年做10-20笔交易
  其中6-7笔小赚（5-15%），2-3笔小亏（-7%止损），1笔大赚（30%+）
  年化收益目标：20-50%（已经非常好了）

不正常的心态：
  "这周怎么没赚到钱" → 利弗莫尔有时几个月不做一笔交易
  "别人都赚了我没赚" → 你只做自己看得懂的信号
  "这次不一样" → 每次都一样，历史一直在重复
```
