## 一、一句话定性

**再升科技是一家主业萎缩、利润骤降、近期刚经历暴力出货的传统材料公司。当前基本面无法支撑158亿市值——276倍PE买一家年利润5600万且加速下滑的公司，逻辑上找不到支撑。**

## 特别章节：这只票真正在交易什么——商业航天概念

> **本节是对初版遗漏的关键补充。初版将其定性为"传统材料公司"，虽在业务层面成立，但完全错过了市场实际在交易的东西。**

### 市场在交易什么：SpaceX + C919

再升科技自2020年起向**"国际某知名航天公司"（市场公认为SpaceX）**直接供应**高硅氧纤维**——一种太空级火箭热防护材料。公司同时是**C919唯一航空隔音隔热棉供应商**，持有AS 9100D航空航天认证。

**这些事实是真的。** 于是股价半年涨了**394%**（从约5元→23.53元），PE一度飙到**729倍**。

### 公司在说什么：占比0.66%，没有订单了

| 公司公告原话 | 大白话翻译 |
|-------------|-----------|
| 航天产品占总营收**约0.66%** | 一年才800多万，≈零头 |
| 目前高硅氧纤维**暂无在手订单** | SpaceX没有再下单 |
| 后续订单存在**较大不确定性** | 连公司都不知下笔订单在哪 |
| 股价存在**击鼓传花效应**，随时快速下跌 | 公司亲口说：这就是博傻 |

### 高潮：高管精准逃顶

| 日期 | 事件 |
|------|------|
| **5月25-26日** | 三名高管在20元附近减持套现599万，窗口期首两天即清仓 |
| **5月27日** | 公告"提前终止减持"——股民以为利好 |
| **5月28日** | 股价冲顶**23.53元**（历史最高，PE 729倍） |
| **5月28日晚** | 公司发最强风险提示："击鼓传花效应明显" |
| **5月29日-6月2日** | **连续三跌停**（-27%） |
| **6月2日** | 公司宣布已固定证据，必要时向公安报案 |

> 实控人郭茂早在2025年10-11月（股价4-5元）已套现**1.37亿元**。

### 散户：5.95万人 → 21.94万人

股东户数半年翻了近4倍。高位进去的，全是散户。

### 三个层面，只有一个是真的

```
业务层：  一家卖滤纸和保温板的公司（营收12.75亿，净利0.56亿）  ← 真实
概念层：  SpaceX + C919 + 商业航天 + 半导体洁净室 四标签        ← 真事但微不足道
交易层：  被"小作文"推上去、高管精准逃顶后雪崩的妖股           ← 残酷真相
```

**这只股票的本质根本不是商业航天——商业航天只是用来讲故事的壳。它的本质是一个传统的、利润在加速下滑的玻璃纤维公司，被包装成了SpaceX概念股，炒到729倍PE后，高管跑了，散户埋了。**

## 三、业务拆解：一家做什么的公司？

### 3.1 三大业务线

| 业务板块 | 2025年收入 | 收入占比 | 同比 | 毛利率（估） |
|----------|-----------|---------|------|-------------|
| **高效节能材料** | 6.71亿 | 52.6% | **-13.57%** | ~20% |
| **干净空气材料** | 4.36亿 | 34.2% | **-18.73%** | ~18% |
| **无尘空调产品** | 1.44亿 | 11.3% | +12.32% | ~25% |
| **合计** | 12.75亿 | 100% | **-13.63%** | — |

### 3.2 各业务通俗解释

| 业务 | 通俗解释 | 下游客户 |
|------|----------|----------|
| **干净空气材料** | 超细玻璃纤维做的滤网、滤纸 | 半导体洁净室、生物医药、核电站 |
| **高效节能材料** | VIP真空绝热板芯材 | 冰箱、冷链物流、建筑保温 |
| **无尘空调** | 带净化功能的家用/商用空调系统 | 高端住宅、医院、商业空间 |

### 3.3 核心判断：业务质地偏传统，缺乏硬壁垒

与雅克科技（半导体前驱体）和风华高科（MLCC）相比，再升科技的业务本质上是**玻璃纤维制品加工**，属于传统制造业范畴：

- 干净空气材料 → 滤纸/滤芯，技术门槛有限，竞争对手众多
- VIP芯材 → 冰箱保温材料，受家电周期影响大
- 无尘空调 → 面向C端的家用产品，品牌和渠道需要长期建设

**这不是一个"卡脖子"赛道，而是一个充分竞争的普通制造业。**

### 4.2 财务三大硬伤

#### 硬伤一：营收和利润双杀，且速度在加快

```
2024年 → 2025年 → 2026Q1
营收：14.76亿 → 12.75亿（-13.6%）→ 3.01亿（-7.3%）
净利：0.91亿 → 0.56亿（-38.2%）→ 0.14亿（-57.4%）
```

净利润下滑速度是营收下滑速度的**3-5倍**，说明不仅是"卖得少"，而且是"卖得便宜"——量价齐跌，且成本刚性。

#### 硬伤二：扣非净利润几乎为零

2025年扣非净利润仅**1,503万元**。一家158亿市值的公司，主营业务扣掉非经常性收益后，一年只赚了不到1600万。

这意味着公司的真实盈利能力已经极度微薄。如果扣除政府补贴、资产处置等非经常性收入，公司在盈亏平衡线上挣扎。

#### 硬伤三：2025年Q4单季亏损

2025年分季度净利润拆解：

| 季度 | 归母净利润 | 说明 |
|------|-----------|------|
| Q1 | ~3,000万（估） | — |
| Q2 | ~2,000万（估） | — |
| Q3 | ~3,100万（估） | — |
| Q4 | **-2,514万** | 单季亏损 |

2026Q1净利润1,431万，虽然环比扭亏，但同比继续大幅下滑57%。**公司的盈利拐点尚未出现。**

## 五、估值分析：276倍PE在交易什么？

### 5.1 估值水平

| 指标 | 数值 | 与同行对比 |
|------|------|-----------|
| PE（TTM） | **~276倍** | 行业均值约30-40倍 |
| PE（静态） | ~279倍 | — |
| 2026E Forward PE | **~165倍**（按0.09元EPS均值） | 极度偏高 |
| PB | **5.88倍** | 行业均值约2倍 |
| 总市值 | 158亿 | — |

### 5.2 估值倒算——当前价格隐含什么预期？

按2026年最乐观的机构预测（长江证券1.66亿净利）：

```
158亿市值 ÷ 1.66亿净利润 = 95倍PE
```

即使是全市场最乐观的利润预测，也仅能支撑95倍PE——仍然很贵。

按机构均值预测（0.97亿净利）：

```
158亿市值 ÷ 0.97亿净利润 = 163倍PE
```

**结论：即使2026年净利润翻倍（从0.56亿→~1亿），当前估值仍然极度偏高。**

### 5.3 机构目标价能信吗？

华泰证券给出目标价**33元**（4月24日报告），当前价约13.7元，看似有140%上行空间。但需注意：

1. **报告发布于4月，当时股价可能不同**——如果当时股价在15-17元，33元目标价意味着翻倍，这在一个利润下滑的公司身上本身就是激进的
2. **华泰在4月已将2026年盈利预测大幅下调68%**——说明基本面在恶化，但目标价调整可能滞后
3. **目标价基于2027年业绩拐点的乐观假设**——VIP板渗透率爆发、石英纤维量产、无尘空调放量……这些都是"如果"而非"已经"

> **对机构目标价，看逻辑不看数字。逻辑是冰箱能效+石英纤维，但这两个故事还需要时间验证。**

## 七、所谓"催化剂"的真相检验

### 7.1 冰箱能效新国标（2026年6月实施）

这是目前最核心的多头逻辑：

| 论点 | 真相 |
|------|------|
| 新国标将大幅提升VIP板在冰箱中的渗透率 | 方向正确，但渗透率提升是渐进过程，非一蹴而就 |
| 公司已打通"玻纤棉→VIP芯材→VIP板"全产业链 | 确有布局，但需要验证能否转化为订单 |
| 新国标6月实施，下半年业绩爆发 | **6月实施≠6月就出业绩**，家电厂的供应链切换需要时间，实际体现在财报上可能要Q4甚至2027年 |

### 7.2 石英纤维"第二成长曲线"

| 论点 | 真相 |
|------|------|
| 有望形成第二成长曲线 | 目前仍处于**研发阶段**，尚未形成营业收入 |
| 技术源自超细纤维底层能力 | 逻辑通顺，但研发→量产→客户验证→订单→收入，至少1-2年 |

### 7.3 无尘空调

- 2025年收入1.44亿，同比+12.32%，是三块业务中唯一增长的
- 但基数极低（占总收入仅11%），且面向C端，品牌/渠道建设需要持续烧钱
- 毛利率约25%，并不算高

## 九、结论

### 9.1 核心判断

| 维度 | 结论 |
|------|------|
| **公司质地** | 🔴 偏弱 — 传统制造业，无硬壁垒，竞争充分 |
| **盈利能力** | 🔴 差 — 营收利润双降，扣非净利几乎为零 |
| **成长性** | 🔴 尚未验证 — 所有催化剂都需要时间，且不确定 |
| **估值水平** | 🔴 极度偏高 — 276倍PE毫无基本面支撑 |
| **资金面** | 🔴 主力出货进行中 |
| **技术面** | 🔴 暴跌通道，虽可能超跌反弹但趋势已坏 |

### 9.2 目标价

**本报告不给出目标价。** 原因是：当一家公司的股价与基本面已经完全脱节时，用PE/PB等估值方法给出的目标价没有实际意义——技术面/情绪面/资金博弈才是当前阶段的主导力量。

如果一定要参考：按乐观情景（2026E净利润1亿 × 40倍PE = 40亿市值），对应股价约**3.5元**。即使给予60倍PE的极度慷慨估值，也仅对应**5.25元**。

> 当前价13.7元与基本面合理价值之间存在巨大鸿沟。

### 9.3 操作建议

| 持仓状态 | 建议 |
|----------|------|
| **如果你持有** | 说实话，在23元跌到14元的过程中，主力已经出了大部分货。每次反弹都可能是减仓窗口。不建议在这个位置继续加仓摊平成本——基本面太弱，摊平=增大风险暴露 |
| **如果你在考虑买入** | 不建议。这家公司的基本面是三只票里最差的，赛道是最传统的，估值是最离谱的，资金面是最恶化的 |
| **如果你只是想博反弹** | 短期超跌（6天跌44%）确实可能出现技术性反弹，但这是在接飞刀，风险极高。如果一定要做，建议极轻仓 + 设3%止损线 |

### 9.4 一句话总结

> **再升科技是一只基本面羸弱、刚刚经历暴力出货、当前仍被严重高估的传统材料股。它和前两家（雅克、风华）不在一个质量层级上。如果三只票只能保留两只，这只应该是最先被淘汰的。**
