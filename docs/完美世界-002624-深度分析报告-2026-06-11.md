## 三、《异环》——这只票的核心变量

### 3.1 为什么《异环》如此重要

完美世界过去20年高度依赖"诛仙""完美世界"两大老IP。老产品自然衰减是确定的，新IP能否接棒决定了公司的生死。《异环》就是用来自我革命的——超自然都市开放世界RPG，UE5引擎，全平台，全球化发行。

**这是一场豪赌，而目前来看，赌赢了。**

### 3.2 《异环》流水时间线

| 时间节点 | 事件 | 市场反应 |
|----------|------|----------|
| 公测前 | 全渠道预约**3,500万+**，创公司纪录 | 股价拉升至17元 |
| 4月23日 | 国内公测，首日**未进iOS畅销榜头部** | 股价一度**触及跌停** |
| 4月29日 | 海外上线，预下载登顶日韩iOS免费榜 | 初步止血 |
| 5月 | 1.0下半卡池开始发力，流水爬升 | 股价12.91元见底 |
| **6月3日** | **1.1版本海外更新 → 日服iOS畅销榜登顶** | **股价6月4日+6.83%** |
| 6月至今 | 海外单日流水**破1亿**，超越国内 | 13-14元震荡筑底 |

### 3.3 关键数据结构

| 指标 | 数据 |
|------|------|
| 首日全球流水 | **超1亿人民币** |
| 首月全球流水（估） | **8-10亿人民币**（注：市场传闻"首月20亿"已被辟谣） |
| 国内PC端流水占比 | **~65%**（渠道分成低，利润率高） |
| 海外PC+PS主机占比 | **~75%** |
| 海外流水贡献 | **已超过国内** |
| 次日/3日/7日留存 | **均优于《幻塔》同期**（公司披露） |

### 3.4 《异环》的核心意义

1. **打破IP依赖：** 完美世界第一次做出非诛仙/非完美IP的大作，证明研发能力
2. **品类突破：** 从传统MMO→都市开放世界+二次元，打开用户天花板
3. **全球化验证：** 海外流水超国内，日服登顶——这是真出海，不是PPT出海
4. **多平台能力：** PC+手游+PS+Mac+鸿蒙全平台，PC占比65%意味渠道费低、利润率优于纯手游

### 4.2 Q1业绩下滑——是问题，但不是陷阱

2026Q1净利润暴跌66%，乍看很吓人。但拆解原因：

| 原因 | 说明 | 持续性 |
|------|------|--------|
| 去年同期高基数 | 2025Q1《诛仙世界》刚上线，流水在峰值 | ✅ 一次性 |
| 《异环》宣发前置 | 上线前营销费用集中发生 | ✅ 已结束 |
| 处置收益不再 | 出售乘风工作室确认1.6亿一次性收益 | ✅ 一次性 |
| 老产品自然衰减 | 诛仙/完美世界IP老游戏流水下滑 | ⚠️ 持续但《异环》可对冲 |

> **Q1的"惨"是事先可预期的，Q2才是《异环》真金白银的开始。**

### 4.3 利润弹性测算

游戏公司的核心财务特征是：**流水的大头变成利润。** 因为研发成本已经前置发生，上线后的新增流水扣除渠道分成（异环PC端占65%，分成极低）和少量运维成本后，大部分直接进入利润。

| 《异环》首年流水假设 | 对应净利润贡献（估） | 2026年总净利润预期 |
|---------------------|---------------------|-------------------|
| 乐观（50亿） | ~15亿 | **~22亿** |
| 基准（35亿） | ~9亿 | **~16-17亿** |
| 悲观（20亿） | ~5亿 | **~10-11亿** |

机构一致预期2026年净利润**16.75亿**，对应基准情景。

## 六、风险因素

### 6.1 核心风险

| 风险 | 严重程度 | 说明 |
|------|----------|------|
| **《异环》流水持续性** | ⭐⭐⭐⭐⭐ | 这是最大的变量。6月是1.1版本红利期，Q3能否维持热度？ |
| **老产品加速衰减** | ⭐⭐⭐ | 《诛仙》《完美世界》IP老游戏可能被《异环》自身蚕食 |
| **二次元赛道拥挤** | ⭐⭐⭐ | 米哈游《原神》《崩铁》、库洛《鸣潮》、腾讯《洛克王国》竞争激烈 |
| **汇率风险** | ⭐⭐ | 海外收入占比提升，人民币升值将侵蚀利润 |
| **影视业务减值** | ⭐⭐ | 历史上有过大幅减值，需持续关注 |
| **Q1的弱势是否延续** | ⭐⭐⭐ | 如果Q2营收仍然同比下滑，市场信心会严重受挫 |

### 6.2 最大风险：游戏流水的高波动性

游戏公司的宿命——**成也产品，败也产品。** 《异环》今天日服登顶，不代表三个月后还在榜上。二次元玩家的口味变化极快，竞品层出不穷。完美世界必须有持续的内容更新能力（1.2、1.3版本……）来维持热度。

**关键跟踪指标：** iOS畅销榜排名、SensorTower月度流水数据、公司每季度的流水披露。

## 八、结论与建议

### 8.1 核心判断

| 维度 | 结论 |
|------|------|
| **公司质地** | 🟢 良好 — 老牌研运一体游戏商，转型关键期 |
| **成长性** | 🟢 爆发期 — 《异环》流水处于上升通道，Q2起业绩弹性巨大 |
| **估值水平** | 🟢 合理偏低 — Forward PE 15.5倍，PEG 0.22，机构目标空间+64% |
| **技术面** | 🟡 筑底中 — 从17元跌到12.91已充分调整，6月初出现放量反弹 |
| **资金面** | 🟡 中性 — 融资余额5连增但主力仍有流出，底部区域特征 |
| **最大风险** | 异环流水能否持续 |

### 8.2 目标价

| 方法 | 目标价 | 权重 |
|------|--------|------|
| PE法（16.75亿净利 × 20倍） | **17.3元** | 40% |

| 机构目标均价 | **21.8元** | 40% |
| **加权综合目标价** | **~20元** | 100% |

> **当前价13.3元，相比综合目标价有约50%上行空间。**

### 8.3 操作思路

| 持仓状态 | 建议 |
|----------|------|
| **考虑新建仓** | 12.9-13.5元区间是近一年低点区域，Forward PE仅15倍，PEG 0.22。如果看好《异环》后续版本表现，当前位置风险收益比是四只票中最优的 |
| **已有持仓** | 关注Q2业绩预告（7月）和《异环》1.2版本流水。如果Q2营收恢复正增长，持有逻辑将得到验证 |
| **止损参考** | 跌破12.9元（前低）建议离场，因为这意味着市场认为《异环》后续不及预期 |
| **核心跟踪** | ①每月SensorTower流水数据 ②iOS畅销榜排名变化 ③Q2业绩预告（7月） ④1.2/1.3版本更新节奏 |

### 8.4 一句话总结

> **完美世界是当前四只票中唯一同时满足"好故事+好价格+已验证催化剂"三个条件的标的。《异环》从公测首日不被看好到日服登顶的逆袭，证明了公司的研发实力和全球化能力。当前13元的股价，对应的是"异环不确定性"的定价；如果异环持续超预期，估值修复至20元是大概率事件。最大的不确定性在于——这款游戏能火多久。**
