## 一、一句话定性

**云南锗业是今天分析的五只票中，故事最硬、逻辑最宏大、但估值也最离谱的一只。它的核心逻辑——中国控制全球铟/锗供给、InP衬底是AI光模块不可替代的瓶颈材料——从产业层面是真实的。但576亿市值、3000倍PE已经把"最好的可能性"定价到了极致。这是一个"对的逻辑、错的价格"的经典案例。**

## 三、业务深度拆解

### 3.1 五大产品线

| 产品线 | 2025年收入 | 占比 | 下游应用 |
|--------|-----------|------|----------|
| **材料级锗**（锗锭/二氧化锗） | 3.64亿 | 34.1% | 基础原材料 |
| **光纤级锗**（四氯化锗） | 2.00亿 | 18.7% | 光纤通信 |
| **光伏级锗**（锗单晶片） | 1.97亿 | 18.5% | 卫星太阳能电池 |
| **化合物半导体**（磷化铟+砷化镓） | 1.38亿 | 12.9% | **AI光模块/射频** |
| **红外级锗**（镜头/热像仪） | 其余 | 15.8% | 军工/安防 |

### 3.2 核心业务① — 磷化铟（InP）：最性感的逻辑

这是整只票的灵魂所在：

```
AI数据中心需要海量高速光模块（800G→1.6T→3.2T）
    ↓
每个光模块需要4-8颗InP激光器芯片
    ↓
InP衬底是激光器芯片的底层材料，不可替代
    ↓
全球能稳定量产大尺寸InP衬底的只有三家企业：
    住友电工（日本，~42%份额）
    AXT（美国，~25%份额，产能在中国北京通美）
    云南锗业（中国，国内唯一，全球第三）
    ↓
铟原料：中国储量73% + 精炼供给85%
    ↓
2025年起中国对铟+InP衬底实施出口管制
    ↓
6英寸InP衬底价格：1400美元 → 5000美元（+257%）
    ↓
谁有国内InP产能，谁就卡住了全球AI的物理脖子
```

#### 云南锗业的InP布局

| 指标 | 数据 |
|------|------|
| 技术地位 | 全球第三家掌握大尺寸InP衬底制备技术 |
| 当前产能 | 年产15万片（折合4英寸） |
| 扩建项目 | 2026年4月获批，新建30万片/年 |
| **建成后总产能** | **年产45万片** |
| 国内市占率 | >60% |
| 竞争对手 | 国内基本没有——这是最大的护城河 |

#### InP需求测算

| 光模块代际 | 单颗InP芯片需求 | 2026年全球光模块出货量（估） | InP衬底需求 |
|-----------|----------------|---------------------------|-------------|
| 800G | 4-8颗 | ~2000万只 | 已有产能勉强覆盖 |
| 1.6T | 12-24颗（3倍于800G） | ~500万只 | 需求爆发 |
| 3.2T | 更多 | 刚开始出货 | 几何级增长 |

> Yole预计2026年全球InP供需缺口**超70%**。住友电工和AXT的产能扩张受制于中国铟原料出口管制，而云南锗业同时拥有铟资源+InP制造能力，是唯一不受管制的玩家。

### 3.3 核心业务② — 光伏级锗：商业航天

| 指标 | 数据 |
|------|------|
| 产品 | 空间太阳能电池用锗单晶片 |
| 用途 | 低轨卫星的太阳能电池衬底 |
| 当前产能 | 125万片/年（折合4英寸） |
| 建成后产能 | **250万片/年** |
| 国内星网计划 | 千颗级低轨卫星组网 |

> 这是白毛股神逻辑的另一个版本——商业航天领域，锗衬底同样是"紫苏叶"。

### 3.4 核心业务③ — 光纤级锗：最稳的底盘

四氯化锗是光纤预制棒的核心掺杂剂。每1亿芯公里光纤需消耗约10吨四氯化锗。全球5G/数据中心光纤建设提供稳定需求。

### 5.2 当前88元在交易什么？

按东吴2028E的16.82亿净利润计算：

```
576亿市值 ÷ 16.82亿净利润 = 34倍PE
```

**88元的股价，已经在按2028年最乐观的利润水平来估值了。** 也就是说，市场把未来两年所有能想象到的好事——InP满产满销、锗价大涨、卫星组网爆发——全部提前兑现到了今天的股价里。

## 八、结论

### 8.1 核心判断

| 维度 | 结论 |
|------|------|
| **产业逻辑** | 🟢 极强 — 中国InP瓶颈是真实存在的战略优势 |

| **确定性** | 🔴 极低 — 连机构预测都差5倍，不确定性极大 |

### 8.3 操作思路

| 情景 | 建议 |
|------|------|
| **如果你相信InP故事但还没买** | 当前价格是在赌2028年。真正的安全边际在30-40元区间（对应东吴2026E 60-80倍PE）。等回调，不要追涨停 |

### 8.4 一句话总结

> **云南锗业拥有今天五只票中最宏大的叙事——中国卡住了全球AI光模块的物理脖子，而它是唯一的国内解。但576亿市值、3000倍PE已经把2028年最好的可能性提前兑现了。如果你以88元买入，你不是在投资InP的稀缺性——你是在赌未来两年一切都按照最完美的剧本运行，不出任何差错。这种赌注，也许白毛股神敢下，但普通人不值得用真金白银去验证。**
