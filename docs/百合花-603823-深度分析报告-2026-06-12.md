## 一、一句话定性

**百合花是一只被"光刻胶"概念点燃的传统化工股。它的基本盘——全球10%份额的有机颜料龙头——是扎实的，但增速缓慢甚至微幅下滑。市场给它的100倍PE，不是买它的颜料业务，而是在赌"面板光刻胶颜料国产替代"这个故事能不能兑现。当前股价已经把"最好的可能性"定价了一大半，剩下的安全边际很薄。**

### 3.2 核心业务 — 有机颜料：扎实但低速的基本盘

百合花是国内唯一具备**全色谱颜料生产能力**的企业，50余条生产线、200多种规格，年产近4万吨，全球份额约10%。

```
全球有机颜料消费量 ≈ 40万吨/年
    ↓
中国产量 27.7万吨（全球第一，占比约70%）
    ↓
百合花产能 4万多吨（国内龙头，全球约10%）
    ↓
下游：油墨40% + 涂料28% + 塑料27% + 特种（化妆品/液晶等）5%
```

**竞争壁垒：**
- **纵向一体化**：关键中间体（4625、色酚系列、DB-70等）大部分自产，参股内蒙古美力坚、控股源晟制钠，控制上游成本
- **横向覆盖**：从传统偶氮到高性能杂环（DPP、喹吖啶酮、二噁嗪等），品类齐全
- **环保门槛**：化工行业环保执法趋严，落后产能退出，龙头受益

**隐忧：**
- 2025年营收同比 **-10.52%**，净利同比 **-5.18%**，主业处于下行通道
- 颜料行业增速与宏观经济高度相关，GDP放缓直接压制需求
- 海外收入仅17%，国际化不足

### 3.3 第二增长曲线 — 光刻胶颜料：最性感的逻辑

这是本轮股价暴涨的核心驱动力：

```
全球LCD面板产能中国占比 ≈ 75%
    ↓
彩色光刻胶是LCD面板关键材料（红/绿/蓝色层）
    ↓
全球彩色光刻胶市场 ≈ 130亿人民币
    ↓
日韩企业占据 >75%份额（DIC等主导）
    ↓
中国光刻胶颜料国产化率仅 ≈ 15%
    ↓
百合花2025年实现技术突破 → 吨级商业化销售
    ↓
国产替代空间巨大 + 毛利率高于传统颜料
```

**百合花的光刻胶布局进度：**

| 时间 | 事件 |
|------|------|
| 2025年上半年 | 液晶面板用光刻胶颜料**技术突破**，实现**吨级销售** |
| 2025年4月 | 公告投资**10亿元**建设高性能有机颜料及配套材料项目 |
| 2025年9月 | 竞得88,045㎡土地 |
| 2025年10月 | 项目**开工仪式** |
| 规划达产 | 预计年产值约**17亿元** |

**这个故事的吸引力在于：**
- 市场空间大（130亿→国产替代空间约110亿）
- 技术壁垒高（此前全球仅DIC等少数企业掌握）
- 毛利率高（光刻胶级颜料毛利率远超传统颜料20%的水平）
- 与面板产业安全直接挂钩（国产化是国家级需求）

**但风险也很大：**
- 目前仅"吨级"销售，距离规模化放量还有很长距离
- 从技术突破→客户认证→批量供货→稳定盈利，每个环节都可能卡住
- DIC等巨头不会坐视市场份额流失，可能降价打压

### 3.4 新能源材料 — 更远期的想象

公司已设立新能源材料研究所，掌握碳酸锂、普鲁士蓝（白）等核心技术，规划"化工材料+新能源材料"双主业。但目前仍处于早期研发阶段，无实质收入贡献。

## 八、核心判断

### 8.1 这是什么类型的标的？

百合花是一个 **"基本面扎实但低速 + 一个高弹性故事"** 的混合型标的。光刻胶颜料的故事是真实的——技术突破、客户认可、产能开建都是事实。但目前的股价已经把这个故事定价到了"接近完美"的程度。

### 8.2 利弗莫尔的视角

> *"我从不买正在上涨的股票——我等它回调，然后看它怎么处理那个回调。"*

百合花6月的涨势太猛（4天3板），真正的考验不是涨了多少，而是**回调时怎么走**：
- 如果缩量回踩30元附近不破，是强势确认
- 如果放量跌回25元以下，说明这波就是炒作

### 8.3 结论

| 维度 | 判断 |
|------|------|
| 主业质地 | ⭐⭐⭐⭐ 扎实，但增速乏力 |
| 光刻胶故事 | ⭐⭐⭐ 真实但早期，不确定性大 |
| 估值合理性 | ⭐ 107倍PE，已严重透支 |
| 当前买点 | ⭐ 短线涨幅过大，追高风险极高 |
| 中长期逻辑 | ⭐⭐⭐ 如果光刻胶放量兑现，2028年后可能值这个价 |

**一句话：百合花是一朵好花，但现在的价格已经开到了2028年的花期。等它凋谢（回调）之后再考虑浇灌。**
