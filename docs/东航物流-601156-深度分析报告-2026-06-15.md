## 二、行业格局：航空货运处于供需偏紧的景气周期

### 2.1 东航物流的商业模式

东航物流依托"天网+地网"双轮驱动：

```
全货机(19架B777) ─┐
                   ├─→ 航空速运（核心引擎，占比45%）
客机腹舱(826架)  ─┘

地面货站(17个)   ──→ 地面综合服务（现金牛，毛利率31%）


跨境电商物流      ─┐
产地直达(生鲜冷链) ├─→ 综合物流解决方案（占比44%）
同业供应链         ─┘
```

### 2.2 需求端：跨境电商长期增长 + 短期地缘红利

| 需求驱动 | 具体影响 |
|----------|----------|
| **跨境电商** | 麦肯锡预测2027年跨境电商占全球空运量近1/3，长期增长确定性高 |
| **中国制造出海** | 高端制造、汽车零部件、电子产品出口持续增长，对空运时效要求高 |
| **中东冲突** | 美以伊局势导致部分欧线运力绕行/收缩，亚太-欧洲即期运价突破5美元/公斤 |
| **医药冷链** | 温控药品空运需求快速增长，门槛高、利润厚 |

**2026年4月IATA数据：**
- 全球航空货运需求(CTK)同比 **+4.0%**
- 全球货运运力(ACTK)同比 **-0.4%**（供给收缩！）
- 亚太航司货运需求 **+10.5%**，全球最高增速
- 上海浦东出口空运运价指数同比 **+24.8%**

### 2.3 供给端：运力刚性约束明显

- 飞机制造商货机交付持续延迟，新机供给不足
- 老旧货机（机龄>25年）加速退役，全球货机保有量增长停滞
- 客改货（P2F）改装线排期满负荷，改装周期18-24个月
- **结论：全球航空货运运力供给在2026-2027年难以大幅扩张，供需偏紧格局持续。**

### 2.4 中国货航的独特竞争优势

申万宏源指出中国货运航司的三大优势：

1. **航程优势** — 可飞越俄罗斯空域，欧美航司需绕飞，单位成本更低、时效更快
2. **需求优势** — 中国为全球最大跨境电商出口国，货源端具有天然优势
3. **运力替代** — 中东局势下欧美航司可能收缩部分欧亚航线，中国航司填补缺口

## 六、核心逻辑链

### 看多逻辑链（主流机构共识）

```
全球航空货运供需偏紧（需求+4%，运力-0.4%）
    +
中东冲突 → 欧线运力收缩 → 运价上行
    +
中国跨境电商长期增长（2027年占全球空运量1/3）
    +
东航物流稀缺性：19架全货机+826架腹舱+17个货站
    +

    ↓

    ↓
当前PE仅10倍，估值处于历史低位

```

## 七、结论与建议

### 7.1 核心判断

| 维度 | 结论 |
|------|------|
| **公司质地** | 优良——稀缺的纯航空货运标的，资产壁垒高（货机+货站+航线），现金流质量优异 |
| **行业景气** | 中等偏上——供需偏紧是客观事实，但运价受地缘事件驱动，可持续性存疑 |
| **估值水平** | 偏低——10倍PE、1.36倍PB在A股物流板块属于估值洼地，高分红提供保护 |
| **技术面** | 短期转多——MACD金叉、放量突破均线，但前高18.35是重要考验 |
| **当前位置** | 风险收益比良好——下行有分红和净资产兜底，上行有估值修复空间 |

### 7.2 操作建议框架

| 持仓状态 | 建议思路 |
|----------|----------|
| **考虑新建仓** | 当前估值合理偏低（PE 10x），适合作为中长期配置标的。建议分批建仓，16.5-17.5区间为合理买入区间 |
| **已持仓** | 基本面未恶化，4%股息率提供了良好的持有回报，建议继续持有等待估值修复 |
| **止损参考** | 若跌破15.30（5月低点），基本面可能出现了未预见的恶化，需重新评估 |

### 7.3 核心跟踪指标

1. **季度运价走势** — 亚太-欧洲/北美航线即期运价是领先指标
2. **航油价格** — 每吨上涨100元→成本增加约5,693万元
3. **全货机日利用率** — 能否维持在13小时以上的历史高位
4. **跨境电商货量** — 中美关税政策变化直接影响综合物流板块
5. **分红兑现** — 2026年中报分红是否延续40%比例

### 7.4 与风华高科的简要对比

| 维度 | 风华高科（000636） | 东航物流（601156） |
|------|-------------------|-------------------|
| PE（TTM） | ~228倍 | **~10倍** |
| PB | ~10倍+ | **1.36倍** |
| ROE | 2.3% | **14.4%** |
| 股息率 | 几乎为零 | **~4%** |
| 行业特征 | 强周期、高波动 | 稳健增长、防御性 |
| 估值状态 | 极度高估 | **合理偏低** |

> 风华高科是"故事驱动型"（MLCC国产替代宏大叙事），东航物流是"价值驱动型"（低估值+高分红+稳健增长）。两者风险收益特征完全不同，适合不同风格的投资者。

### 7.5 一句话总结

> **东航物流是一家具稀缺资产壁垒、现金流优异、估值处于洼地的价值型标的。** 10倍PE+4%股息率为中长期投资者提供了充足的安全边际。当前技术面刚刚发出底部反转信号，17.29元处于合理估值区间，适合分批布局。核心风险在于运价的周期性波动和油价上行对利润的侵蚀，但只要分红政策稳定，长期持有的回报确定性较高。
