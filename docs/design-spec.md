# 设计规范 — A股实时筛选App

## 设计原则
- **简洁**：去除一切非必要元素，信息层级清晰
- **直观**：筛选进度和结果一目了然
- **移动优先**：为手机屏幕设计，触控友好

## 配色方案

| 用途 | 颜色 | 色值 |
|------|------|------|
| 主色（背景） | 淡蓝 | `#EBF3FB` |
| 主色（卡片/按钮） | 中蓝 | `#4A90D9` |
| 主色（强调） | 深蓝 | `#2C5F8A` |
| 文字（主要） | 深灰 | `#333333` |
| 文字（次要） | 中灰 | `#666666` |
| 上涨 | 红色 | `#E53935` |
| 下跌 | 绿色 | `#43A047` |
| 分隔线 | 浅灰 | `#E0E0E0` |
| 背景（白色区域） | 白色 | `#FFFFFF` |

## 组件规范

### 按钮
- 圆角：8px
- 主按钮：中蓝底白字，高度44px（方便手指点击）
- 最小点击区域：44×44px

### 股票卡片
- 白色背景，圆角12px
- 轻微阴影（`0 2px 8px rgba(0,0,0,0.1)`）
- 内边距16px
- 卡片间距12px

### 进度指示器
- 6个圆点横向排列
- 已完成：蓝色实心
- 进行中：蓝色边框闪烁
- 未开始：灰色空心

### 字体
- 标题：18px，加粗
- 正文：14px
- 辅助文字：12px
- 数字：等宽字体（monospace）

## 响应式断点
- 手机（< 768px）：单列布局，全宽卡片
- 平板及以上（≥ 768px）：最大宽度600px居中
